# CollabLab — мультиплеер-компилятор

Совместный редактор кода в реальном времени: XML-валидация, компиляция C# (dotnet сервер), HTML-превью и чат комнаты — всё синхронизируется между участниками через WebSocket.

## Возможности

- **Комнаты** — ссылка на комнату = место встречи; участники видят код друг друга в реальном времени (редактор-зеркало, курсор, индикатор «печатает…»)
- **XML** — мгновенная валидация в браузере (статистика тегов/глубина/корень)
- **C#** — компиляция и запуск на сервере (dotnet), stdout/exit-код видны обоим
- **HTML** — живое превью прямо в браузере у каждого участника
- **Файлы проекта** — общее хранилище файлов комнаты (все операции на сервере)
- **Чат комнаты** — текстовый чат между участниками (WS, история хранится на сервере)
- **AI-ассистент** — встроенный чат с OpenDeep (DeepSeek), видит текущий код комнаты
- **Аккаунты** — регистрация/вход, сессии с cookie, никнеймы участников

## Запуск

```bash
pip install opendeep        # опционально, для AI-чата
export DEEPSEEK_API_KEY=... # опционально
python3 server.py --host 0.0.0.0 --port 8282
```

Для C#-компиляции нужен отдельный HTTP-сервис на `http://127.0.0.1:8081/compile`, принимающий `{"code": "..."}` и возвращающий `{"success": bool, "stdout": "...", "stderr": "..."}`.

## Структура

```
server.py      — asyncio HTTP + WebSocket сервер (auth, комнаты, файлы, чат, AI)
www/index.html — авторизация и список комнат
www/room.html  — редактор, файлы, чат, AI
```

Сервер хранит данные рядом с собой: `users.json`, `sessions.json`, `project/<комната>/`.

## WebSocket протокол

Клиент → сервер: `join{room,kind,xml}`, `edit{xml}`, `cursor{pos}`, `compile{xml}`, `fsel{file}`, `chat{text}`, `list`.

Сервер → клиент: `welcome{room,kind,peers,name,names,chat}`, `peers{count,names}`, `peer{xml}`, `cursor{pos}`, `run{result}`, `error{msg}`, `peerf{file,peer,name}`, `files`, `chat{name,text,time}`.
